# Getting started

Install the public package beside an existing Nextra 4 application:

```bash
pnpm add next-ai-ready zod@^4
pnpm exec next-ai-ready init
```

Keep Nextra's plugin in place, then wrap its resulting Next.js config:

```js
import nextra from "nextra"
import { withAiReady } from "next-ai-ready/config"

const withNextra = nextra({})
const nextConfig = withNextra({})

export default withAiReady({ agentReadable: true })(nextConfig)
```

Build both representations from the same MDX source:

```bash
pnpm exec next-ai-ready build
pnpm build
```

The HTML page remains available at `/getting-started`; its explicit Markdown representation is
available at `/getting-started.md`.
