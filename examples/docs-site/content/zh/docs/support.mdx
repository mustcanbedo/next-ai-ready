# 支持 next-ai-ready

`next-ai-ready` 采用 MIT 许可证，开源核心会继续免费。最有价值的支持方式，是在真实 Next.js 项目中使用它，并告诉我们安装、生成结果或文档在哪一步不够清楚。

## 支持开源项目

- 在真实项目中[安装 npm 包](https://www.npmjs.com/package/next-ai-ready)。
- [提交可复现的问题](https://github.com/mustcanbedo/next-ai-ready/issues/new/choose)。
- 分享一个其他维护者可以检查的公开接入案例。
- 如果项目确实进入了你的工具链，可以为 [GitHub 仓库加星](https://github.com/mustcanbedo/next-ai-ready)。

这些信号通常比匿名赞助更有价值，因为它们能说明哪些问题值得长期维护。

## 固定范围诊断

维护者同时通过 AI Website Audit Lab 提供付费的 **Next.js 搜索与 AI 可见性诊断**。这是与开源 SDK 分离的专业服务。

适合以下情况：

- Next.js 生成页面的 Google 收录不稳定；
- canonical、sitemap、robots、metadata 或结构化数据互相冲突；
- AI 系统无法发现或读取重要内容的干净版本；
- 在修改生产代码前，需要一份有优先级的实施方案。

首次诊断 **299 美元起**，范围为一个生产站点和事先约定的代表性页面模板。付款前，我们会以文字确认范围、可用证据、交付日期和准确价格。

### 你会收到

- 一份有证据的技术与内容可访问性问题图谱；
- 对渲染、HTTP 状态、canonical、sitemap、robots、metadata、结构化数据、内部发现路径及相关 AI 可读产物的检查；
- 带验收标准的实施优先级清单；
- 一次用于解释结论的书面答疑。

代码实施、页面重新设计、持续内容工作和分析埋点会在诊断后单独报价。首次公开 URL 检查不需要生产权限；只有获得明确授权后，才会查看 Search Console 或其他私有证据。

## 证据边界

SDK 和诊断可以改善技术可访问性并发现实现问题，但**不保证**被收录、获得排名、产生流量、线索或收入，也不保证出现在 AI 生成的回答中。
