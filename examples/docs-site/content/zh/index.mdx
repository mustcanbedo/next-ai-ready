# next-ai-ready

`next-ai-ready` 是**面向 Next.js 的 AEO 与 Agent-API 基础设施层**。它让现有站点更容易被 AI 系统发现和读取，同时将经明确授权的应用功能暴露给 Agent。

## 它提供什么

- 通过 `llms.txt`、`sitemap.md`、逐页 Markdown、JSON-LD 和语义图谱提供 **AI 可读知识**。
- 通过类型安全的 Action、OpenAPI 3.1、`tools.json` 和 MCP 提供 **Agent 可调用能力**。
- 通过 `next-ai-ready doctor` 和 `next-ai-ready audit <url>` 提供**部署检查**。
- 使用开放标准，不锁定单一 AI 提供商。

## 安装

```bash
pnpm add next-ai-ready@alpha
npx next-ai-ready init
npx next-ai-ready build
```

框架会在不替换可视页面的前提下，增加机器可读路由与构建产物。
