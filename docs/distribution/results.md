## Recording rules

1. Keep the UTM URL from [README.md](./README.md) unchanged for the first campaign.
2. Add the public post URL immediately after publishing.
3. Record 24-hour and seven-day outcomes even when every value is zero.
4. Count an adopter issue only when an external maintainer submits a real project or setup blocker.
5. Count a verified install only when it meets the definition in
   [early-adopter-operations.zh-CN.md](../early-adopter-operations.zh-CN.md).
6. Stop or change a channel after the seven-day review; do not rewrite an unsuccessful result as a
   product success.
