# next-ai-ready

`next-ai-ready` is the **AEO and Agent-API infrastructure layer for Next.js**. It makes an existing site easier for AI systems to discover and retrieve, while exposing explicitly authorized application features to agents.

## What it provides

- **AI-readable knowledge** through `llms.txt`, `sitemap.md`, per-page Markdown, JSON-LD, and a semantic graph.
- **Agent-callable capabilities** through typed actions, OpenAPI 3.1, `tools.json`, and MCP.
- **Deployment checks** through `next-ai-ready doctor` and `next-ai-ready audit <url>`.
- **Open standards** with no dependency on a single AI provider.

## Install

```bash
pnpm add next-ai-ready@alpha
npx next-ai-ready init
npx next-ai-ready build
```

The framework adds machine-readable routes and build artifacts without replacing the site's visual pages.
