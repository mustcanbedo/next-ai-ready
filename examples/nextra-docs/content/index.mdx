# Nextra AI-ready fixture

This is a real Nextra 4 documentation site, not a static screenshot or a configuration snippet.

The browser experience remains owned by Nextra. `next-ai-ready` reads the same MDX files and adds
discovery and retrieval endpoints for AI systems.

## What this fixture proves

- Nextra still renders the human-facing documentation UI.
- `/llms.txt` lists the documentation pages.
- `/getting-started.md` returns clean Markdown.
- `Accept: text/markdown` negotiates the same page as Markdown.
- Unknown browser routes remain real `404` responses.
