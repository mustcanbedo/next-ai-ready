# next-ai-ready

约 10 分钟，为 Next.js App Router 站点增加供 AI 工具发现和读取的内容入口。需要时，再添加经过鉴权的 Agent Action。

## 10 分钟开始

```bash
pnpm add next-ai-ready zod@^4
pnpm exec next-ai-ready init
pnpm exec next-ai-ready build
pnpm exec next-ai-ready doctor --score
```

当 `doctor` 显示 **0 个错误**，且 `public/llms.txt` 已列出你的内容时，基础接入即完成。构建前请在生成的配置中指向你的 MDX 或 Markdown 内容。

## 它提供什么

- 通过 `llms.txt`、`sitemap.md`、逐页 Markdown、JSON-LD 和语义图谱提供 **AI 可读知识**。
- 通过类型安全的 Action、OpenAPI 3.1、`tools.json` 和 MCP 提供 **Agent 可调用能力**。
- 通过 `next-ai-ready doctor` 和 `next-ai-ready audit <url>` 提供**部署检查**。
- 使用开放标准，不锁定单一 AI 提供商。

本文档站跟随 `main`，npm 的 `latest` 与 `alpha` 当前均为 `0.1.0-alpha.17`。已发布包在此前验证的运行时与审计能力上，新增根目录与 `src/` 内容发现、正确的 Nextra/Fumadocs 路由以及 MCP 页面搜索的 locale 过滤。

## 已验证的可读性基线

生产文档站于 2026 年 8 月 1 日使用 Vercel 开源的 `@vercel/agent-readability@0.5.0`，在全部 25 项检查中获得 **100/100**。

- [机器可读原始结果](https://github.com/mustcanbedo/next-ai-ready/blob/main/docs/audit-baselines/vercel-agent-readability-0.5.0-2026-08-01.json)
- [定期 Agent Readability 工作流](https://github.com/mustcanbedo/next-ai-ready/actions/workflows/agent-readability.yml)
- 本地运行 `pnpm audit:vercel:site` 可复现

该第三方工具分数仅衡量技术层面的 Agent 可读性，不保证排名、收录或引用。
