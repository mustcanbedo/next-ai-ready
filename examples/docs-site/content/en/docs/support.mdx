# Support next-ai-ready

`next-ai-ready` is MIT-licensed and its open-source core remains free. The most useful way to support it is to run it in a real Next.js project and tell us where the installation, generated output, or documentation falls short.

## Support the open-source project

- [Install the package](https://www.npmjs.com/package/next-ai-ready) in a real project.
- [Report a reproducible issue](https://github.com/mustcanbedo/next-ai-ready/issues/new/choose).
- Share a public implementation that other maintainers can inspect.
- [Star the repository](https://github.com/mustcanbedo/next-ai-ready) if it has earned a place in your toolchain.

These signals help more than an anonymous donation because they show which problems are worth maintaining.

## Fixed-scope diagnostic

The maintainer also offers a paid **Next.js search and AI visibility diagnostic** through AI Website Audit Lab. This is a professional service separate from the open-source SDK.

It is a good fit when:

- generated Next.js pages are not being indexed consistently;
- canonical URLs, sitemaps, robots rules, metadata, or structured data disagree;
- AI systems cannot discover or retrieve a clean representation of important content;
- you need a prioritized implementation plan before changing production code.

The initial diagnostic starts at **USD 299** for one production site and an agreed set of representative page templates. Before any payment, we confirm the scope, evidence available, delivery date, and exact price in writing.

### What you receive

- an evidence-backed map of technical and content-accessibility findings;
- checks across rendering, HTTP status, canonical, sitemap, robots, metadata, structured data, internal discovery, and AI-readable outputs where relevant;
- a prioritized implementation backlog with acceptance criteria;
- one written follow-up to clarify the findings.

Implementation, page redesign, ongoing content work, and analytics instrumentation are quoted separately after the diagnostic. No production access is required for the initial public-URL review. Search Console or private evidence is reviewed only after explicit authorization.

## Evidence boundary

The SDK and diagnostic can improve technical accessibility and reveal implementation problems. They do **not** guarantee indexing, search rankings, traffic, leads, revenue, or inclusion in an AI-generated answer.
